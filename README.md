# OLED 절감형 UI 디자인 시스템 라이브러리

OLED 화면의 전력을 디자인 단계에서 줄일 수 있도록 돕는 웹 기반 UI 디자인 시스템 라이브러리입니다.
Material Design 3(M3)를 그대로 두고, 에너지 절감을 위해 달라지는 부분만 규칙으로 더한 프로파일 방식으로 구성했습니다.

**바로 열기:** https://jihee2217.github.io/oled-saving-ui-library/

## 주요 기능

- **색상 토큰별 BW Index** — Primary, Background, Text를 조정하면 토큰마다 상대 소비 지수(Black = 0, White = 1)를 보여 줍니다. 실측한 여덟 색의 기준값을 3선형 보간하여 계산합니다.
- **대비 3단계** — 본문 대비를 WCAG 2.2 AA(4.5:1), AAA(7:1), 높음(11:1)의 목표에 맞춥니다. 절감 규칙과 접근성이 부딪히면 접근성을 따릅니다.
- **두 절감 모드와 Saving UI** — 어두운 절감형과 밝은 절감형에서 26개 컴포넌트 묶음별 추천 조합과 사용 규칙을 제시합니다.
- **디자인 도구 연계** — 정한 값을 디자인 토큰 묶음(.zip)으로 내보내고, `figma-plugin/`의 플러그인으로 Figma에 가져올 수 있습니다.

BW Index는 상대 지표이며, 특정 화면의 절대 전력이나 절감량을 예측하지 않습니다.

## 로컬에서 쓰기

`patterns.html`을 브라우저로 열면 설치나 서버 없이 사용할 수 있습니다. 소스를 고친 뒤에는 Node.js에서 빌드와 테스트를 실행합니다(외부 패키지 없음).

```sh
npm run build
npm test
```
